# STM32 智能药盒

基于 STM32F103C8 的智能药盒控制程序。设备根据实时时钟和设定的服药计划发出提醒，并通过开盒检测判断是否取药。

## 功能

- 使用 DS3231 实时时钟读取和设置时间
- 支持设置 3 个药盒的服药时间
- 到达计划时间后，通过语音模块和蓝牙串口提醒
- 检测对应药盒是否打开
- 未按时开盒时启动蜂鸣器和振动提醒
- 使用 TFT 屏幕显示时间和提醒状态
- 通过蓝牙串口接收时间和服药计划

## 硬件

- 主控：STM32F103C8
- 实时时钟：DS3231
- 显示屏：TFT
- 语音模块：LU6288
- 蓝牙串口模块：连接 USART3
- 蜂鸣器和振动马达
- 三路药盒开盒检测输入

以下引脚根据当前源码整理，实际接线请以硬件电路为准。

| 蓝牙 USART3 TX / RX | PB10 / PB11 |
| 语音模块 USART1 TX / RX | PA9 / PA10 |
| DS3231 软件 I2C SCL / SDA | PB6 / PB7 |
| TFT DC / CS / SCK / MOSI | PA3 / PA4 / PA5 / PA7 |
| TFT 复位 | PB12 |
| 蜂鸣器 | PB0 |
| 振动马达 | PB1 |
| 药盒 0 开盒检测 | PA8 |
| 药盒 1 开盒检测 | PA11 |
| 药盒 2 开盒检测 | PA12 |

## 蓝牙串口指令
